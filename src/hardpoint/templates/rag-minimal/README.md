# {{ project_name }}

Question answering over the documents in `docs/`, generated by
`hardpoint init --template rag-minimal` (hardpoint {{ hardpoint_version }}).

## Run it

```bash
cp .env.example .env            # add OPENAI_API_KEY, or skip and use --env offline
hardpoint doctor                # config, keys, extras, index, dimensions
hardpoint ingest run --plan     # what would be embedded, and what it costs
hardpoint ingest run
hardpoint ask "How do I rotate an API key?" --explain
```

No key yet? Every command takes `--env offline`, which swaps the models for
deterministic local fakes (see `config/offline.yaml`). Nothing leaves the machine.

## What is where

| Path | What it is | Change it when |
|---|---|---|
| `pipelines/rag.py` | The pipeline, step by step. Read it top to bottom: that is what runs. | You want a different retrieval strategy: add a step to the list. |
| `prompts/answer.md` | The answer prompt. Versioned by content hash. | You want a different voice or format. |
| `prompts/abstain.md` | What is said when nothing relevant was found. | Always. It is your product's voice. |
| `config/base.yaml` | Which components, and their settings. | You switch provider, index, or tune `top_k`. |
| `config/offline.yaml` | Local fakes, for CI and for trying it without keys. | Rarely. |
| `config/prod.yaml` | Production overlay: redaction on, tighter budgets. | Before deploying. |
| `docs/` | The corpus. | Point `sources.docs.root` at your own documents. |

Re-running `hardpoint ingest run` over an unchanged corpus embeds nothing, and
editing one paragraph re-embeds only the chunks it touched.

## Test it

```bash
pip install -e ".[dev]"
pytest
```

The tests ingest `docs/` and answer a question with the offline fakes, so they
run in CI with no keys and no network.
